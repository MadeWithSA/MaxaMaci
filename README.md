# MaxaMaci — магазин косметики (React + Vite)

    npm install
    npm run dev      # разработка
    npm run build    # сборка в dist/

Страницы: главная, каталог (поиск, фильтры, сортировка), карточка товара, корзина с оформлением, о нас.
Языки: RU / UZ / EN. Тема: светлая / тёмная. Корзина, язык и тема сохраняются в браузере.
Товары и переводы — в src/data.js.
